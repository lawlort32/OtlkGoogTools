# OtlkGoogTools - The Ultimate Outlook & Google Toolkit MCP Server

## Features
- Seamless integration with Outlook and Google services.
- No Azure registration required using Microsoft's public client applications.
- Zero-config authentication for easier setup.

## Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/lawlort32/OtlkGoogTools.git
   ```
2. Navigate into the directory:
   ```bash
   cd OtlkGoogTools
   ```
3. Start the server:
   ```bash
   npm start
   ```

## Installation
Follow the steps below to install the necessary packages:

```bash
npm install
```
