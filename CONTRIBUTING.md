# Contributing Guidelines

Thank you for your interest in contributing to the OtlkGoogTools project! We welcome contributions from the community. Please follow the guidelines below to ensure a smooth process:

## Setting Up Your Development Environment

1. **Clone the Repository:**  
   Run the following command to clone the repository to your local machine:
   ```bash
   git clone https://github.com/lawlort32/OtlkGoogTools.git
   ```

2. **Install Dependencies:**  
   Navigate to the project directory and install the required dependencies. For example:
   ```bash
   cd OtlkGoogTools
   npm install
   ```

3. **Run the Project:**  
   Once the dependencies are installed, you can run the project to ensure everything is working:
   ```bash
   npm start
   ```

## Coding Standards

- Follow the coding style guidelines stated in the project's documentation.
- Ensure that your code is well-commented and follows best practices for clean code.
- Run any code formatting tools before submitting your changes (e.g., Prettier, ESLint).

## Pull Request Process

1. **Create a New Branch:**  
   Create a new branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. **Make Your Changes:**  
   Implement your feature or fix in your branch.

3. **Commit Your Changes:**  
   Use clear and descriptive commit messages.
   ```bash
   git commit -m "Add feature: your feature description"
   ```

4. **Push to Your Branch:**  
   Push your changes to your branch on GitHub:
   ```bash
   git push origin feature/your-feature-name
   ```

5. **Create a Pull Request:**  
   Navigate to the repository on GitHub and create a pull request. Provide details of the changes you've made and any relevant information.

## Community Guidelines

- Be respectful and constructive in discussions.
- Be open to feedback and willing to improve.
- Help foster an inclusive environment for all contributors.

Thank you for contributing to OtlkGoogTools! We're excited to see what you bring to the project!
